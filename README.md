# Parqueadero Autos Colombia - Sistema de Gestión

## Descripción
Sistema de información para la gestión de entradas y salidas de vehículos 
en el parqueadero "Autos Colombia", el cual opera por **mensualidad**.

## Iteración 1
Esta primera iteración contempla:
-  Registro de entrada de vehículos con validación de mensualidad.
-  Registro de salida de vehículos.
-  Control de aforo (cupos disponibles).
-  Bloqueo automático de vehículos sin contrato activo.

## Tecnologías utilizadas
-  Python 3.x
-  MySQL 8.x
-  mysql-connector-python

## Requisitos
- Python instalado
- MySQL Server corriendo
- Base de datos creada (ver `database/script.sql`)
